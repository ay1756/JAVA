【脚本设计要点】
- 全部 GBK 编码、无 BOM、且必须是 CRLF(\r\n) 换行（否则 cmd 解析首行即崩）。
- 项目内用 %~dp0..\xxx 相对路径；工具用 dir /s /b + %USERPROFILE% 通配探测。
- start-all 用 start "标题" cmd /K 子脚本，各开独立窗口；子脚本末尾 pause 防闪退。
- stop-all 先按窗口标题 taskkill，再按端口 8081/5173 清残留。

【致命坑：.bat 必须 CRLF，不是 LF】
- 现象：双击运行后，窗口里每一行都报"XXX 不是内部或外部命令"（chcp/title/cd/set/echo 全中招）。
- 根因：.bat 文件用了纯 LF(\n) 换行。cmd 按 CRLF 解析，遇到 \n 会吃掉该行第一个字符，
  于是 `chcp` -> `hcp`、`cd` -> `d`、`echo` -> `cho` 全部"命令不存在"。
- 怎么造出来的：用 Write 工具写 UTF-8，再 Python 转 GBK 的那条链会【保留 LF 不变】，
  结果是"GBK 对了、换行却还是 LF"，肉眼看不出，cmd 直接全崩。
- 修正方法（Python）：open 后 content.replace('\n','\r\n')，再以 GBK 无 BOM 写回；
  写完后务必核验：用 Python 数 CRLF 行数 > 0 且 LF-only 行数 == 0，首字节是 '@'，无 BOM。
- 校验脚本（已删，需要时照写）：
  for f in files: b=open(f,'rb').read(); print(f, 'CRLF=',b.count(b'\r\n'),'LF=',b.count(b'\n')-b.count(b'\r\n'),'BOM=',b[:3]==b'\xef\xbb\xbf')
