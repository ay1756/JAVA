## 二、另一台电脑必须提前装好的环境

脚本会自动探测这些工具；若探测不到会明确提示缺什么。请在新电脑装好：

1. **Node.js（含 npm）** —— 建议 18+ / 22。官网 https://nodejs.org 下载安装版，装完 `npm` 会自动加入 PATH（脚本优先用 PATH 的 npm）。
2. **JDK 17** —— 安装后脚本会按以下顺序找：`JAVA_HOME` 环境变量 → `C:\Program Files\Java\jdk-17` → `C:\Program Files\Java\jdk-*`。都不在就自行设置 `JAVA_HOME`。
3. **Apache Maven 3.9.x** —— 后端编译运行靠它。脚本找：`mvn`（PATH）→ IDEA 缓存 `~\.m2\wrapper\dists\apache-maven-3.9.9\*` → `C:\Program Files\Apache\Maven\*` → `C:\maven`。
4. **MySQL 8.x** —— 服务名、账号密码见下。

> 说明：`scripts/` 里的脚本**不再写死本机路径**（旧的 IDEA 缓存 Maven、WorkBuddy 托管 node 路径已去掉），换机按上面装好即可被自动找到。

## 三、数据库怎么带到新电脑

**不需要单独拷贝数据库文件。** 项目里已经带了两份 SQL：

- `springBootTest/sql/init_safe.sql`：只建库 / 建表 / 补 `admin/123456`、`traveler/123456` 两个种子账号，**绝不删除已有数据**（幂等，可反复跑）。
- `springBootTest/sql/sky_login.sql`：完整建库脚本（含 `DROP`，仅首次用）。

新电脑只要装好 MySQL（**账号 `root`、密码 `123456`**），运行 `scripts/start-backend.bat` 时会**自动执行 `init_safe.sql`** 把 `sky_login` 库建好。

若新电脑 MySQL 的**服务名不是 `MySQL84`** 或**密码不是 `123456`**：
- 改 `scripts/start-backend.bat` 顶部的 `set "MYSQL_SVC=MySQL84"` 和 `MYSQL_PASS` 即可。
- 服务名也可在脚本运行时被自动跳过（提示“服务名无效”时，请手动启动 MySQL 再重跑）。

> ⚠️ 不要试图直接拷贝 MySQL 的 `data` 数据文件夹来迁移——那玩意跟 MySQL 版本、操作系统强绑定，跨机基本打不开。用上面的 SQL 脚本才是正道。

## 四、怎么运行（解压后）

> ✅ **确认结论**：只要新电脑按第二节装好 Node / JDK17 / Maven / MySQL，双击 `start-all.bat`（管理员）后，**前端（5173）和后端（8081）都能起来**。
> - 前端首页（`/main` 蓝天页、`/home` 资讯页）即使后端没起也能看（纯静态）。
> - 登录 / 注册功能需要后端 + MySQL；脚本启动时会自动建库（`init_safe.sql`），无需手动导数据。
> - 若其中某个工具没装，对应脚本会明确报错“未找到 XXX”，装好重跑即可，不会悄悄失败。

1. **建议用管理员身份**运行（因为脚本要 `net start MySQL` 拉起数据库服务，普通权限会被拒绝，但数据库那步失败不影响前端）。
2. 双击 **`scripts/start-all.bat`** —— 会自动开两个窗口：
   - `Sky后端`：端口 **8081**（先建库、再编译启动，首次会下载依赖，稍慢）
   - `Sky前端`：端口 **5173**（先 `npm install`，再起 Vite）
3. 浏览器打开 **http://localhost:5173/** 即可看到效果：
   - `/` → 登录页；`/register` → 注册页；`/welcome` → 欢迎页
   - `/home` → 云国资讯页；`/main` → 蓝天白云首页
4. 停止：双击 **`scripts/stop-all.bat`**，或关掉两个窗口。

## 五、打包（压缩）前请排除以下东西，否则压缩包会非常大

这些文件夹/文件都是**可以自动重建或无关紧要**的，打包时请排除（用 7-Zip / WinRAR 添加排除项，或手动删掉再压）：

- `sky-login-vue/node_modules/`（前端依赖，脚本会自动 `npm install` 重建）
- `sky-login-vue/dist/`（构建产物，可重建）
- `springBootTest/target/`（后端编译产物，脚本会 `mvn clean` 重建）
- `springBootTest/.idea/`、`springBootTest/.git/`（IDE / 版本库，无关）
- `springBootTest/log/`、`springBootTest/backend-run.log`（运行日志，无关）
- `springBootTest/新建文件夹`（空文件夹，无关）

> 如果嫌麻烦，不删也行，只是压缩包会大很多（node_modules 通常几百 MB）。

## 六、常见问题

- **前端能开、登录报网络错误**：后端没起来。看 `Sky后端` 窗口日志；多半是 Maven / JDK / MySQL 没装好或密码不对。
- **双击 bat 一闪而过**：右键“以管理员身份运行”，或在 bat 末尾本就有 `pause`，若仍闪退说明前面 `exit /b 1` 了——按提示装缺失环境。
- **中文乱码**：脚本已统一转 GBK 编码；若仍乱码，确认用 `cmd` 运行（不是 PowerShell 直接拖入），且系统区域为中文。
- **`mvnw` 用不了**：本项目 `mvnw` 缺 `maven-wrapper.jar`，不能直接自举，请按第二节装 Maven。
